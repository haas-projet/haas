# ADR-002 — Atelier collaboratif

**Date :** 1er octobre 2026. **Statut :** mécanismes conservés ; positionnement complété par ADR-005.

## Décision technique conservée
F13 cas communautaires, F14 comparaison de deux implémentations approuvées B1 et F15 fiche de vérification. L’utilisateur garde ses outils. Aucun code utilisateur exécuté. Cas documentaires et scénarios livrés via CI restent distincts. B2 conserve son protocole navigateur ; copie de contexte IA reste P1.

## Priorité de présentation révisée
ADR-005, adopté après le mail, place désormais projets, développeurs, échanges et connaissances au premier plan. L’atelier est une branche distinctive, non un passage obligatoire. Les règles de comparaison ci-dessus restent actives. Sources courantes : cahier consolidé, COMMUNAUTE_ET_PROJETS, ATELIER_COLLABORATIF et architecture ; aucune archive absente n’est requise.

## Suivi
Les identifiants BV201–BV210/FV201–FV205/RV201 sont conservés. Les compléments BC/FC suivent ADR-005. Une application existante n’est pas réinitialisée ; migrations, contrats et tests sont ajoutés. Le backend nouveau est reçu avant les nouveaux écrans. La charge antérieure n’est pas une estimation de l’ensemble.

Le dossier est une conception, pas une application installée ni une preuve de développement.
