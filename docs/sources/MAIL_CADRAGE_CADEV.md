## Extrait du message

Cette année, vous allez devoir construire sur le thème :

> Une plateforme d'échange pour les développeurs, par les développeurs et pour les développeurs.

Imaginez un espace où les développeurs peuvent **se retrouver, échanger, poser des questions, partager leurs connaissances, présenter leurs projets et collaborer entre eux.**

Un espace pensé autour des usages réels des développeurs : **discuter, apprendre, partager, découvrir et construire ensemble.**

Votre mission est de réfléchir à **la meilleure expérience possible pour permettre à une communauté de développeurs d'échanger et de collaborer.**

À vous de décider :
- Comment les développeurs se rencontrent ;
- Comment ils échangent ;
- Comment ils partagent leurs projets ;
- Comment ils collaborent ;
- Et surtout, ce qui rendra votre plateforme réellement utile.

## Portée
