# Identité HAAS
Sources : PNG générés et fournis dans la conversation, réexportés sans changement de concept.
`haas-logo.png` : logo horizontal. `haas-icon.png` : symbole. `icon-*.png` et `favicon.ico` : tailles de déploiement.
Ces fichiers restent matriciels, pas des SVG vectoriels. Aucun fichier de police n'est redistribué. Vérifier le favicon sur fond clair et sombre dans le navigateur livré ; les variantes ne constituent pas une validation de marque.
La signature de l’atelier est portée par l'interface et les supports, sans altérer le sous-titre Help as a Service du logo.
